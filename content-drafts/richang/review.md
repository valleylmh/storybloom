## 插图与内容

- 沿用「城市汽车小队」的安安、妈妈及人类漫画人物风格，新增爸爸、奶奶和朋友乐乐。
- 每页单独使用内置 `image_gen`，原始分镜与实际生成提示词保存在对应 JSON 的页面记录中；未使用图片生成 API 脚本。
- 最终插图位于 `public/library/richang/<bookId>/<page>.webp`，均为 1200×1200、每张不超过 300 KiB；124 张图片的文件哈希互不相同。
- 每本联系表位于 `content-drafts/richang/<bookId>/contact-sheet.jpg`，已逐本检查人物、动作、物品状态与叙事顺序。
- 已修正新鞋颜色、小车毛线、饼干数量与人物服装、牛奶杯外观、妈妈开衫及野餐毯颜色的连续性问题。
- 《烂苹果》保留及时享用、减少将就的寓意；腐烂苹果丢弃，食用场景为新鲜水果。
- 每本包含独立的亲子目标、共读提醒、两个讨论问题、生活活动与分龄提示。关闭固定页数的个性化生成入口。
