# StoryBloom 公开工程路线图

> 产品愿景与阶段说明见 [ROADMAP.md](../ROADMAP.md)。本文档只保留当前可验证的交付状态、下一阶段工程任务和验收边界，不再记录一次性迁移事故、供应商故障或会话过程。

## 总览

| 模块 | 状态 | 说明 |
|---|---|---|
| 8 页个性化绘本生成 | 已实现 | 年龄适配、固定故事节奏、文本 fallback、异步逐页插图 |
| 角色一致性与家庭角色库 | 已实现 | 角色参考、身份锁定、页级出场角色、私有照片存储 |
| 绘本馆 | 已实现 | 成语故事、西游记、科普问答，独立 URL 与 SEO |
| 阅读、朗读、分享和视频 | 已实现 | 系统朗读、PNG/ZIP、公开链接、浏览器本地视频 |
| 每日绘本灵感 | 已实现 | 双重确认订阅、每日内容、重复投递保护 |
| 自助 PDF / 打印版 | 规划中 | 近期优先 |
| 读后互动 | 规划中 | 近期优先 |
| 阅读进度、收藏与成长档案 | 部分实现 | 本地 GrowthMoment / 多绘本版本、照片与版本独立删除；云端未接线 |
| 连续故事世界 | 长期方向 | 角色、地点与故事线跨作品延续 |

建议当前实施顺序：**PDF → 读后互动 → 阅读进度与收藏 → 成长档案 → 连续故事世界**。内容安全与质量基线可以与这些任务并行推进。

## 已交付能力

### A. 生成与角色一致性

- 文本生成遵守 2–3、4–5、6–8 岁年龄规则和固定 8 页故事节奏。
- `Character Bible`、主角身份锁定和 `castIds` 已进入生成提示词；家庭角色只在实际出场页面传入参考图。
- `/api/generate` 先返回故事文本和待生成页面；前端再逐页调用 `/api/illustration`，服务端接受任务后后台生成并由前端轮询结果。
- 图片 Provider 支持配置顺序、限流、回退、页级失败记录和手动重试。
- 无模型凭据时保留与主题相关的本地文本 fallback 和演示图片，便于安全自托管。

### B. 绘本馆与内容生产

- `/library` 提供成语故事、西游记和「好奇为什么」系列；成语上线 30 本、科普上线 10 本，西游记上线 60 回；每本 8 页。
- 馆藏书使用静态数据、稳定 URL、sitemap、canonical、Open Graph 和结构化数据。
- 馆藏内容采用“草稿生成 → 人工审核 → 插图审核 → 发布”的流程，脚本与操作说明见 [scripts/README.md](../scripts/README.md)。
- 系列角色卡与逐页提示词资产保存在 `docs/library-prompts/` 和 `docs/sample-book-prompts/`。

### C. 阅读、媒体与分享

- 用户作品保存在浏览器最近记录中，可继续查看和删除。
- 网页朗读使用浏览器 `SpeechSynthesis`；真实 MP3 只在带旁白视频等需要音频文件的场景按需生成。
- 已支持 PNG 长图、图片 ZIP、公开阅读链接、分享图片持久化和一次性删除令牌。
- 绘本视频在浏览器本地渲染，视频状态与现有生成、朗读、分享状态相互隔离。

### D. 家庭角色与隐私基础

- 登录用户可以创建可复用的孩子、家人和宠物角色。
- 上传照片先在浏览器缩放并重编码为 WebP，从而移除原文件 EXIF。
- 家庭照片保存在 Supabase 私有 Storage，并通过用户目录和 RLS 隔离。
- 临时自定义角色参考图默认 24 小时过期；家庭角色及公开分享均提供删除路径。

## 下一阶段任务

### E. 自助 PDF 与打印排版（P1）

**目标**：让家长把已经生成的绘本保存为适合家庭打印和收藏的文件。

任务边界：

1. 优先采用浏览器端生成，避免把排版和字体成本放进服务端请求。
2. 支持封面、8 页正文、献词和末页；第一版采用横向 A4。
3. 中文字体必须在常见桌面和手机浏览器中稳定显示。
4. 用户生成绘本和馆藏绘本复用同一导出核心。
5. 不把付费、邮件门槛或印刷供应商接入与第一版 PDF 强耦合。

验收标准：

- [ ] 8 页绘本 PDF 小于 15 MB，中文不乱码。
- [ ] A4 打印预览没有裁切或溢出。
- [ ] 手机 Safari、Chrome 和桌面 Chrome 能触发下载。
- [ ] PDF 失败不影响现有 PNG、ZIP、分享或视频功能。

### F. 亲子共读小问题（P1）

**目标**：在不把产品变成考试工具的前提下，为每本馆藏书增加 2–3 个适龄讨论问题。

任务边界：

1. 先使用 `LibraryBook.quiz` 的预留数据，只在经过人工审核的馆藏内容中启用。
2. 阅读结束后展示选择题或开放讨论提示，答案用于即时解释，不记录儿童能力分数。
3. 第一版使用纯客户端状态，不改变用户生成 API 的成本和数据结构。

验收标准：

- [ ] 至少一个馆藏系列完成问题数据与人工审核。
- [ ] 阅读结束后的选择、反馈和解释流程完整。
- [ ] 关闭互动后，原有阅读体验完全不变。

### G. 阅读进度与收藏（P1）

**目标**：为成长档案建立低风险、客观的阅读事实基础。

任务边界：

1. 未登录用户先用本地存储记录已读、最近阅读和收藏。
2. 登录同步保持可选，复用现有家庭账号体系，不强制创建孩子档案。
3. 只记录作品、时间、进度和家长主动操作，不从阅读速度推断能力。

验收标准：

- [ ] 刷新后仍保留本地阅读进度和收藏。
- [ ] 用户可以清空本地记录。
- [ ] 登录同步失败不影响本地阅读。

### H. 家长可控的成长档案（P1，依赖 G）

**目标**：让每一本故事在家长确认下成为长期故事世界的一部分，而不是给孩子建立隐藏画像。

当前本地 v1 已把真实 `GrowthMoment` 与 `StorybookVersion` 分离，支持旧 IndexedDB 幂等兼容、多版本切换、分别删除版本/现场照片/整个时刻。云端 migration 仅为未部署基础，账户同步、导出、保留期限和推荐解释仍未完成，不能视为本阶段整体交付。

任务边界：

1. 记录客观信息：作品、阅读次数、收藏、故事主题、喜欢的角色和家长笔记。
2. 兴趣和“下一本书”方向必须由家长确认；模型建议不能直接写入长期档案。
3. 不创建心理、情绪、性格、智力或学习能力评分。
4. 保存功能必须同时提供查看、导出、单条删除、完整删除和保留期限设置。
5. 匿名用户保持本地优先；登录后的云同步必须显式选择。
6. 多个孩子使用独立档案，不能仅以账号或家庭名称混合记录。

验收标准：

- [ ] 家长可以看到系统保存了哪些字段以及保存原因。
- [ ] 家长可以修改、导出和删除全部成长档案。
- [ ] 关闭长期记录后仍可正常生成、阅读和分享绘本。
- [ ] 推荐下一本书时清楚展示使用了哪些家长确认信息。

### I. 连续故事世界（P2，依赖 H）

**目标**：让熟悉的角色、地点和故事线跨多本绘本延续。

任务边界：

1. 在现有角色一致性机制上增加可版本化 Character Bible，而不是另起一套角色系统。
2. 由家长选择哪些人物、地点或未完故事可以进入下一本书。
3. 每次生成仍允许从零开始，不把历史设定强制注入所有故事。
4. 孩子参与采用有限、适龄的选项，不开放无边界对话或未经家长确认的长期记忆。

验收标准：

- [ ] 同一故事世界中的角色和地点可被查看、编辑和停用。
- [ ] 新故事明确列出将复用的设定。
- [ ] 删除故事世界后，不再把其内容用于后续生成。

## 持续性工作

### 内容安全

- 在现有提示词约束之外增加独立的输入、文本输出和图片输出检查。
- 对儿童照片、家庭资料和公开分享建立清晰的保留期限与删除策略。
- 安全检查失败时应安全降级，不把供应商错误暴露为用户内容违规。

### 质量基线

- 建立固定主题、年龄段和角色参考的回归样本集。
- 先用人工量表验证年龄适配、故事连贯、角色一致、图片安全和语言质量。
- 自动评分只作为辅助信号；在可靠性验证前，不因单次模型评分自动消耗用户额度重生成。

### 开源维护

- 新环境变量同步更新 `.env.example` 与 README。
- 行为变更运行 `npx tsc --noEmit` 和相关测试；日常 UI 迭代不运行生产构建。
- 不提交真实儿童照片、客户绘本、生产密钥、联系人二维码或本地生成缓存。
