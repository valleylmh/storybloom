# 六一与生日礼物绘本

两本独立的虚构人物公开样书，加入 `/gifts` 精品绘本合集，复用立体阅读器；每本一张封面、五个完整跨页（十页正文）。未接入真实孩子资料，也未发布上线。

| 主题 | 书名 | 本地路由 | 素材目录 |
| --- | --- | --- | --- |
| 六一礼物 | 今天，快乐最大 | `/gifts/joy-day` | `public/gift-books/joy-day/` |
| 生日礼物 | 你是今天的小星星 | `/gifts/birthday-star` | `public/gift-books/birthday-star/` |

## 内容与视觉

- 六一：出门迎风 → 纸船与梦想 → 分享泡泡和笑声 → 树荫下休息 → 把快乐留在心里。薄荷绿、阳光黄、朱红风车，短发黄背带裤主角。
- 生日：生日清晨 → 发现成长 → 弄糟也能重新尝试 → 家人的祝福与许愿 → 每一岁都被爱。暖桃色、奶油黄、星空蓝，双辫红裙主角。
- 所有正文中文字直接由内置 `image_gen` 连同插画生成，无额外 HTML 文字叠层。每本封面为该册内页的人物与风格参考，书脊附近避开文字和人物脸部。
- 原始封面 1086×1448，跨页 1536×1024。每个跨页按左右两半呈现，单页比例为 3:4。
- 保留 PNG 原图；阅读使用相同尺寸的高质量 WebP，以减少加载体积。`<slug>-artwork.zip` 包含封面、五个跨页 PNG 和逐页文字说明。

## 实现

内容与赠言：`src/components/gifts/illustrated-gifts.ts`。

封面、打开、合上、分享与下载：`src/components/gifts/IllustratedGift.tsx`。沿用既有 `GiftReader` 的双面翻页、左右纸张堆叠、键盘与触摸操作、减少动态效果支持。没有增加放大按钮，也没有改动绘本馆或扩大首页广告。

本地分享按钮给出未上线提示；公网环境使用系统分享或复制阅读链接。原图下载只读取静态 ZIP。
