# StoryBloom Sample Book Image Prompts

These prompts are grouped by featured sample book. Each file contains:

- A reusable global style prompt.
- A character or cast consistency prompt.
- Eight page-level image prompts.
- A shared negative prompt.

Suggested workflow for external image platforms:

1. Paste the global style prompt and consistency prompt before every page prompt.
2. Keep the same aspect ratio and seed strategy across all 8 pages when the platform supports it.
3. Generate each page separately, then choose the most consistent set.
