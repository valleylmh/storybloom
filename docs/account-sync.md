# 统一账号记录

登录后 `/me/books`、`/me/growth` 与 `/growth` 使用一份账号记录列表。未登录的创作继续保存本机。新保存内容通过全局 AccountSyncProvider 同步；页面可见时每 30 秒刷新，联网、回到窗口和本机保存也触发同步。当前设备的未绑定历史记录首次登录后归属该账号；已归属另一账号的记录不进入自动上传候选。含现场照片的记录只有在当前账号获得一次监护人授权后才上传。

上传复用 local-data-import 的稳定 ID、私有 WebP 上传、白名单快照和双端冲突判断。账号缓存存于以 user id 为键的独立 IndexedDB 记录，不作为另一个书架显示。尚未上传的本机记录和云端记录按稳定 client id 合并。已同步过但云端不存在的记录按已删除处理，不能被旧设备重新上传。删除和编辑需要联网；网络失败提示重试，不伪报完成。账号切换后的异步结果不能发布到新账号界面。同步冲突保留内容，并由账户页「同步详情与版本冲突」处理。

本地缓存的云端图片 URL 有有效期，离线时不保证所有图片可见；重新联网会签发新 URL。账号页阅读绘本时先保存图片字节再打开阅读器。

## 当前边界

账号成长列表同步现有成长记录及其当前绘本；本机高级档案中的无绘本时刻、多版本选择尚未接入完整的云端档案仓库。现有本机数据保留，但不能将本次验证解释为这些高级档案的跨设备验收。已缓存完整图片的绘本支持离线打开；未缓存的图片仍需要联网。同步与修改通过队列串行执行，部分修改失败后也重新读取账号状态。关联绘本已被远端删除的成长记录暂停自动上传，避免隐式恢复已删除绘本。
