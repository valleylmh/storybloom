# 日常系列视觉锁定

沿用「城市汽车小队」的人类漫画人物与 3D 动画电影质感，方形 1:1 插图，温暖日光、柔和材质、生动表情与真实的城市家居环境。

安安：6 岁中国女孩，圆脸，齐耳黑色短发，左侧黄色星星发夹，青绿色外套、牛仔裤、白色红边运动鞋。鞋子故事中按分镜区分灰色旧鞋、白色红边新鞋及袜子。

妈妈：齐肩黑发、珊瑚色开衫、米色长裤。爸爸：短黑发、深蓝毛衣、米色长裤。奶奶：银灰短发、淡紫开衫。乐乐：同龄中国男孩，黑色短发、芥黄色上衣、深蓝裤子。

第三批新增：小宇是同龄中国男孩，黑色短发、森林绿上衣、炭灰长裤，与乐乐区分。老师是扎起黑发、鼠尾草绿开衫的中国成年女性。公园工作人员是穿无标识蓝色上衣的中国中年女性。睡前安安穿浅黄色无图案睡衣，星星发夹放在床边小碟里。

第三批物品连续性：安安的小车底部是蓝圆点，乐乐的同款小车底部是绿三角；两车都是红色、圆车灯、黑车轮。丢失的小熊是棕色、蓝丝带，离开公园后的真实场景不再出现，只可在安安的画中出现。乐乐收到纸帽的玩具小熊是红丝带；纸帽始终为蓝色、黄色星星。系鞋带时练习对象是安安脚上的白色红边鞋，爸爸只按分镜协助，不把成人自己的鞋作为练习对象。

每页只加入分镜指定的人物，不把全体角色描述作为每页必画的角色清单。家里保留浅绿色橱柜、橡木餐桌及熟悉的窗景。远景、对话中景、表情与物品近景交替，避免连续重复构图。

第四批新增：熟识的邻居阿姨是短栗色头发、天蓝色开衫、炭灰长裤的中国中年女性，与妈妈、奶奶区分。孩子打招呼时保持舒服的距离，不画拉拽、强迫拥抱或围观。

第四批物品连续性：《那句话卡在嘴巴里》是蓝色积木桥和原木色小船；先有一侧倒塌，修复后桥洞变宽。《生气的小手放哪里》是红屋顶积木房、门口蓝色圆形小地垫，小宇找的是绿色小球。《那辆小车，我今天就想要》的新玩具归乐乐所有，始终是黄色遥控车、黑色遥控器；安安自己的原有小车是红色普通小车，愿望本里的黄车只是画，不暗示买到了。《这一集，我还想看》的平板是灰色外壳，动画只含无文字的抽象圆形与小桥；手机和平板在收好后的场景不得继续亮着。《我还没说，眼泪就来了》的画是蓝色小河、红色花，纸张空白角只有泪水痕，画笔筒为黄色。《我只想吃这一种》紫薯饼干为紫色，原味为米色，小碗为青绿色；吃空后的盘碗保持空。《你一吃，我也想吃》的小点心盒为青绿色；食物只在坐稳、清洁双手后入口。《这次真的不是我》是橙色颜料，小宇绿色袖口沾少量橙色，安安举画离开桌面，事实与误会必须在图中分清。

No text, letters, captions, speech bubbles, logos, watermark, animal families or anthropomorphic animal protagonists. 绘画与家务图仅使用无文字图形。玩具和小熊形饼干是物品。

《烂苹果》：腐烂苹果只做挑出与丢弃，食用画面必须是明确新鲜的苹果；不示范削掉腐烂处后食用。《新鞋》：物品与人物的鞋子对应清楚，不为了统一服装而破坏情节。

连续性验收：每本建立联系表，核对角色身份、物品变化、人物动作与文本、场景时间以及食物状态。所有页确认后再开放阅读；旁白按最终中文文本生成、核对内容哈希与逐页时间轴。
