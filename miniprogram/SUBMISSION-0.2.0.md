# 0.2.0 版本资料

状态：已上传微信开发版本，未提审、未发布。用户已确认真机效果可用。

版本说明：210 本双语绘本，支持在线中英文朗读与自动翻页、分类吸顶、可视区域封面加载、收藏与续读；修正 iPhone 静音模式朗读。

功能介绍：展示六个系列的 210 本完整中英绘本，共 1778 页。支持搜索和分类、逐页阅读与插画放大、阅读指南，以及中文、英文和中英连续朗读。图片读取现有网站公开资源，点击播放后调用网站接口生成当前页音频。收藏和阅读位置保存在本机，无需登录。

体验路径：首页选择任一绘本，点击播放体验朗读；可切换语言、手动翻页、暂停和收藏。返回首页切换我的书架继续阅读。

本版包含音频播放，提审时需如实描述，不能沿用 0.1.0 的“无音视频”说明。
