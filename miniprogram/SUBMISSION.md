# 0.1.0 提审资料

版本号：0.1.0

版本说明：首版提供六本完整绘本的中英图文展示，支持搜索、分类、翻页、插画放大、阅读指南、本机收藏与阅读进度。

功能介绍：面向亲子共读的绘本图文展示工具，展示成语、古诗、经典故事与基础科普内容。所有图文随程序包提供，无需登录；收藏与阅读进度仅保存于当前设备。无音视频播放、课程销售、支付或用户发布内容功能。

审核体验路径：首页可直接查看六本绘本，点击封面进入阅读；底部上一页／下一页翻页，点击插画可放大，右上方可收藏和查看阅读指南。返回首页后切换「我的书架」可查看最近阅读与收藏，并继续上次阅读位置。

服务类目：用户后台当前已选择「教育服务 → 教育信息展示」，提交时如实保留功能描述，以平台实际审核反馈为准。

上传工程：miniprogram/release，实际代码目录 dist。无需测试账号、OSS 域名或业务后端。

当前状态（2026-09-06）：0.1.0 已通过微信开发者工具 CLI 上传，返回 upload 成功；平台包体 1,373,844 字节。上传回执位于被 Git 忽略的 release/upload-info.json。尚未提审、未发布。
